# Refined SauceCodePro punctuation

This build is based on SauceCodePro-Custom-Punctuation.

- Exclamation stem: more pronounced fully convex inverted-bowling-pin shape.
- Exclamation spacing: slightly larger stem-to-dot gap.
- Percent slash: one continuous band; standalone fraction slash unchanged.
- Percent dots: slightly larger and shifted outward for more whitespace.
- Previous reversed slashed-zero and amplified-tilde changes are retained.
